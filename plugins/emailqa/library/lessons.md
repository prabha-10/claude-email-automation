# Team lessons

Generic lessons learned from real builds and Litmus runs, added by the team. The build-email skill reads this file before writing MJML, together with the plugin's own house rules.

Add a lesson when a fix would help any future email, not just one client. One bullet each: the problem, the fix, and which client showed it.

- (example) Gmail App dark mode: a dark logo on a transparent PNG disappears. Fix: add a light outline to the dark parts, or give the logo a solid background. Seen in Gmail App Dark.
